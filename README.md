# פרחי שמיים — חמש חוויות עיצוב

כתובת קבועה לכל הגרסאות: https://yosef4613.github.io/pirchei-shomayim-designs/

- פרמיירה — תאורת במה, צילום ועומק.
- נואר — מגזין מוזיקלי ותקליט אינטראקטיבי.
- אורורה — צילום המקהלה ופסל גלי קול.
- היכל האור — במה רחבה ותאורה קולנועית.
- סימפוניה — דיוקן מוזיקלי, תנועה וגלריית קליפים.

כל חמש הדוגמאות כוללות את תוכן המקהלה, אוסף השירים, תוכנית החוג בירושלים, מקהלולם ופרטי ההרשמה. בוחרים עיצוב בסרגל בראש האתר. הכתובות הישירות `premiere.html`, `noir.html`, `aurora.html`, `lumiere.html` ו־`symphony.html` נשמרות לצד הדף הראשי.

## תוכן ומקורות

- [ערוץ המקהלה](https://www.youtube.com/@-pircheishomayimboyschoir7232): תיאור המקהלה ושמונת הסרטונים שבאוסף.
- [אתה בחרתנו](https://www.youtube.com/watch?v=-4sE-rfQI1k): הקרדיטים, הסיפור ופרטי ההרשמה לתשפ״ז, בהתאם לתיאור הסרטון שנמסר.
- שתי מודעות ירושלים שסופקו: תוכנית החוג, שיטת משה בערק, גילי 8–12, מבדק ההתאמה, קבוצה מתקדמת והטבת החודש האחרון לילדים משנה קודמת. המקור בעברית ובאנגלית זמין בעמוד החוגים.
- הלוגו השקוף המקורי והאייקון של הענן עם התו נשמרו מתוך מדיית אתר פרחי שמיים, ללא המרה מה־PDF. סמל פרחי שמיים מופיע בצבעיו המקוריים. הסרטון המונפש של הלוגו אינו נכלל באתר.
- תמונת הפרופיל והבאנר נלקחו מערוץ המקהלה. תמונות שמונת הקליפים הורדו מ־YouTube באיכות 1280×720 ונשמרו ב־`assets/covers/`.
- `assets/covers/sources.json` מתעד את כתובת הסרטון, מקור התמונה ושיוך הערוץ שנבדק באמצעות YouTube oEmbed.

## שימוש ועדכון

אתר סטטי ללא תלות בבנייה או בספריות חיצוניות. `app.js` מחזיק את התוכן והפעולות; `site.css` ו־`upgrade.css` מחזיקים את הפריסות והאנימציות. הגופנים, הלוגו, התמונות והמודעות מקומיים. הנגן פונה ל־YouTube רק לאחר לחיצה.

הטופס מכין פנייה בתוכנת הדוא״ל של המשתמש, ומסביר שעליו להשלים שם את השליחה. הוא אינו שומר פניות במסד נתונים. מספר הטלפון הראשי מיועד לשיחות קוליות בלבד; קישורי WhatsApp מפנים רק למספרי המתנ״סים שנמסרו.

אין באתר כתובות הרשמה מקוצרות או מנוחשות מתוך תיאור הסרטון. פרטי המתנ״סים מוצגים עם חיוג, דוא״ל ו־WhatsApp; נווה יעקב מפנה לאתר המינהל הקהילתי.

הורדת תמונות המקור ושיוך הערוץ ניתנים לבדיקה מחדש באמצעות workflow `Verify channel media`. התהליך מפיק artifact לבדיקה ואינו משנה את קובצי האתר אוטומטית.

בדיקות: חמש דוגמאות במחשב ובנייד; מעבר בין עיצובים במקלדת; חיפוש וסינון; פתיחת נגן וסגירה; תפריטי נייד; בחירת עיר; תוכן ההרשמה, קישורי יצירת קשר וטעינת כל התמונות המקומיות. הפחתת תנועה מכבדת גם את העדפת מערכת ההפעלה.
