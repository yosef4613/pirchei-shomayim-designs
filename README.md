# פרחי שמיים — שלוש הצעות עיצוב

דוגמאות אינטראקטיביות לאתר מקהלת פרחי שמיים.

- `index.html`: השוואה בין שלושת העיצובים.
- `premiere.html`: במה קולנועית עם תאורה נעה.
- `noir.html`: מגזין מוזיקלי עם תקליט מסתובב.
- `aurora.html`: אורורה עם פסל גלי קול מונפש.

התמונות והגופנים כלולים בקובצי ה־HTML. הסרטונים נפתחים ב־YouTube. הטופס מכין הודעת דוא״ל ואינו שומר פניות בשרת.

## צפייה

פתחו את כתובת GitHub Pages של המאגר. לפיתוח מקומי אפשר לפתוח את `index.html` ישירות בדפדפן.
