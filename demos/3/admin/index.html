המייל לכל פנייה חדשה נשלח לכתובת של המקהלה, ולהורה נשלח אישור אוטומטי.

מנויים

כל מי שהצטרף לעדכונים, מהטופס לחוג או מההרשמה לעדכונים. מנוי מקבל רק את הנושאים שבחר, ויכול להסיר את עצמו בכל עת.

דיוור

בוחרים תבנית, ממלאים פעם אחת את הפרטים, ובודקים את המייל לפני השליחה. העדכון יוצא רק למנויים שבחרו בנושא.

החוגים

מה שמעדכנים כאן מופיע מיד בכרטיסי החוגים באתר, בעברית ובאנגלית.

    הופעות

    כשיש הופעה, מוסיפים אותה כאן והיא מופיעה באתר באזור ״ההופעה הבאה״. אחרי התאריך היא עוברת לבד להופעות קודמות. בשנה בלי הופעה האזור פשוט מציג את ההופעות הקודמות.

    הוספת הופעה

      מאחורי הקלעים

      תיעודים והסברים מהחזרות ומהאולפן. סמנו ״בלעדי לאתר״ כדי שיופיע עם תווית מיוחדת.

      הוספת תיעוד

        שירים

        השירים נמשכים אוטומטית מהפלייליסט הרשמי ביוטיוב. כאן אפשר רק לבחור שיר מומלץ ולהסתיר שיר מהאתר.
